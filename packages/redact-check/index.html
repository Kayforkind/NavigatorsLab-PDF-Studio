What this check does and does not prove
  • It finds solid dark rectangles in the rendered page and reports text whose glyphs sit beneath one and are fully painted over. That is the failure mode where a redaction was drawn on top instead of applied.
  • A clean result means no text was recovered from under the boxes it found. It does not prove an image, a scanned page, or a dark photograph beneath a box is gone — those are pixels, and pixels cannot be checked this way.
  • It cannot see boxes drawn in a light colour, as a translucent overlay, or outside the visible page area. It also only reports text that is still rendered; text removed from the content stream but left in metadata or attachments is a different check.
  • Character boundaries in a recovered string are approximate: proportional fonts mean the slice can be a character or two wide of the mark. The point is that the text is there.

Built on PDF Studio's rendering pipeline. If a box turns out to be fake, PDF Studio redacts for real — the bytes are deleted and the export refuses to hand you a file that still leaks.
