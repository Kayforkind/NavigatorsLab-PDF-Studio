# Forms

Fill real AcroForms — text fields, checkboxes, radio groups, dropdowns — then
flatten them so nobody can change your answers.

## Fill a form

1. Open a fillable PDF and press **Forms** in the top bar.
2. Every field is listed — text, checkbox, radio group, dropdown — with
   jump-to-page buttons.
3. Toggle **"show fields on pages"** to draw the widgets on the page itself;
   clicking one scrolls the dialog to it and focuses that field.
4. **Save** writes your values into the real AcroForm fields.

## Flatten

After filling, **flatten** burns the values into the page content so they can't
be changed downstream. Flattened forms are just page content — no longer
editable fields.

## Add form fields yourself

Use the `F` (text field) and `C` (checkbox) tools to place new fillable fields
on any page, then export.

## Automate it

The CLI and MCP server currently focus on text editing, redaction, and page
operations — see the [CLI reference](/guide/cli) and [MCP tools](/guide/mcp).
